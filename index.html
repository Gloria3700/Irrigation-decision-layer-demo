REAL PUBLIC CONTEXT

Why the Authion irrigation setting is a useful research pilot

Public descriptions of the Authion basin show collective allocation, many withdrawal points, annual allocation planning, changing crop-water needs and drought constraints. The A3P project explicitly aims to combine crop-water-demand modelling with AI-based hydrological availability forecasts for dynamic irrigation management.

~600irrigating farms in the Authion basin
16–18k hairrigated annually
23–30 Mm³annual irrigation withdrawals reported publicly
~2,200surface- and groundwater withdrawal points
10management units in the collective allocation framework
A3Pcrop demand + hydrology + AI + satellite information
What already exists?

Collective allocation and in-season monitoring

Public material describes annual water-volume requests, individual and collective review, an annual allocation plan, volume monitoring and collective reductions when demand exceeds available water.

  • Inventory of users, withdrawal points, crops and water sources
  • Annual allocation planning across management units
  • Withdrawal monitoring and drought restrictions
  • Rotational irrigation schedules, notifications and dashboards
What is the research gap?

From monitoring to forecast-informed action

The missing layer is not another forecast model. It is the logic that decides which predictive information should change which action, in which operational state, and under which decision strategy.

    WP C · STRATEGY COMPARISON

    Keep both state and forecast fixed. Change the decision strategy.

    The action is not fixed. It is the strategy output. If two strategies recommend the same action, this prototype assigns them the same physical management consequence; the more complex method must then justify itself through robustness, constraint handling or another operational benefit.

    FIXED current state + forecast → CHANGED decision strategy → compare action + consequences + complexity

    Turn retained forecast-to-action logic into a traceable decision service

    A first operational version does not need to control irrigation automatically. It can run in shadow mode: generate a recommendation beside current practice, log the rationale, and compare recommended versus actual actions and outcomes.
